# DeepClean96 — концепт сайта-визитки

Статический адаптивный сайт для демонстрации возможному клиенту. HTML + CSS + JavaScript без сборщика и платных сервисов. Подходит для Vercel, Cloudflare Pages, GitHub Pages и любого статического хостинга.

## Быстрый запуск

1. Распакуйте ZIP.
2. Откройте `index.html` в браузере. Для максимально точной проверки (особенно буфера обмена) запустите локальный HTTP-сервер: `python3 -m http.server 8000` и откройте `http://localhost:8000`.
3. Для Vercel: загрузите содержимое папки в новый репозиторий GitHub, затем откройте **Vercel > Add New > Project > Import Git Repository**. Альтернатива через CLI: запустите `npx vercel --prod` в папке проекта. Framework Preset: **Other**, Build Command не нужен, Output Directory: `.`.
4. Перед публикацией как официального сайта **обязательно получите разрешение владельца** и подтвердите название, цены, телефон, материалы, услуги и способ обработки заявок. Только после согласования удалите демо-предупреждения и запреты индексации в `index.html`, `vercel.json`, `robots.txt`.

## Структура

- `index.html` — семантическая структура, SVG-спрайт и секции сайта.
- `styles.css` — оформление, адаптивность, анимации, стили калькулятора.
- `config.js` — настраиваемые название, телефон, адрес, услуги и тарифы. Для изменения прайса редактируйте только этот файл: карточки услуг, прайс и калькулятор автоматически обновятся.
- `app.js` — логика калькулятора, копирование запроса, мобильное меню, появление блоков.
- `assets/` — 8 оригинальных SVG-изображений (логотип, иллюстрация первого экрана и 6 иллюстраций услуг).
- `vercel.json` / `robots.txt` — защита от индексации демонстрационной версии.
- `make_illustrations.py` — необязательный скрипт, воссоздающий иллюстрации услуг. Сайт не требует Python и не запускает этот скрипт.

## Как работает расчёт

- Сумма рассчитывается **только как минимальный ориентир** из опубликованных цен: диван от 2 500 ₽, матрас от 1 200 ₽, кресло/стул от 350 ₽, ковёр 500 ₽/м², кожаная мебель от 1 500 ₽.
- Автохимчистка указана как направление работы, но цена в этом проекте **не установлена** и выводится «по запросу».
- Можно добавить несколько видов услуг, удалить их, очистить расчёт и скопировать подготовленный текст.
- Кнопка **«Скопировать запрос»** работает только с буфером обмена. Никаких заявок, персональных данных или платежей сайт не отправляет.
- Нет фейковой CRM, подключённой формы или заявленных скидок. Фотографии реальных работ не использованы: все изображения являются оригинальными декоративными SVG-иллюстрациями.

## Передача владельцу — чек-лист

- Подтвердить право использовать наименование и графику (логотип в проекте — оригинальный концепт, а не официальный логотип).
- Сверить прайс, материал мебели, минимальный заказ, выезд, ограничения по загрязнениям.
- Получить настоящие фотографии работ «до/после», согласовать права на изображения.
- Подтвердить телефон, мессенджеры, точный формат работы и корректный адрес.
- Согласовать текст обработки персональных данных и действующий способ связи/приёма заявок; при необходимости добавить серверную интеграцию.
- Настроить собственный домен и SSL, обновить метаданные и удалить демо-дисклеймеры только после одобрения.

## Дизайн и доступность

Сайт использует оригинальный SVG-спрайт и векторные иллюстрации, минимальное количество рамок, анимации появления на `IntersectionObserver`, плавные переходы, мобильное меню, раскрывающиеся FAQ, доступные подписи форм. Для пользователей с `prefers-reduced-motion` анимации отключены. Шрифт Manrope загружается из Google Fonts, при его недоступности используется системный шрифт.
